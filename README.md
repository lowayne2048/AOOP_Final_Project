# Toilet Waiting Simulator

等廁所模擬器是 AOOP（物件導向程式設計）課程的期末專題，使用 Python 與 Pygame 開發。

## Project Overview

本專題以等待廁所為主題，透過遊戲模擬排隊與廁所使用的情境。

詳細遊戲規則、物件設計及預計功能請參考 [PROJECT_PROPOSAL.md](PROJECT_PROPOSAL.md)。

## Technologies

- Language: Python
- Game Library: Pygame
- IDE: Visual Studio Code
- Version Control: Git / GitHub

## Getting Started

### 1. Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install Pygame

```bash
python -m pip install pygame
```

### 3. Run the game

```bash
python main.py
```
